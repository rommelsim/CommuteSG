## Common Questions

**Why are arrival times different from the station board?**
Commute pulls directly from LTA DataMall, the same source as official displays. Small differences (10-30 seconds) can occur due to network refresh timing.

**Location isn't working**
Check Settings > Commute > Location is set to "While Using the App."

**An MRT station or bus stop is missing**
Stop and station data comes from LTA. If something looks wrong, email us and we'll check.
